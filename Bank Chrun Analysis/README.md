# Bank Churn Analysis Dashboard

## Overview

Customer churn is one of the biggest challenges for banks because losing existing customers can impact long-term revenue and growth.

This project analyzes customer churn using Power BI to understand customer behavior and identify the factors that influence whether customers stay with or leave the bank.

The dashboard provides interactive visualizations that help users explore churn patterns across different customer segments and support data-driven decision-making.

## Objective
• Analyze customer churn and retention.
• Identify customer groups with higher churn.
• Compare customer behavior across different demographics.
• Build an interactive dashboard that allows users to explore the data through filters and navigation.

## Dashboard Features
### KPI cards for:
• Total Customers
• Active Customers
• Exit Customers
• Churn Rate
• Retention Rate
• Average Credit Score
### Interactive analysis by:
• Geography
• Age Group
• Gender
• Tenure
• Credit Card Status
• Activity Status
• Year
Interactive slicers for quick filtering.
Bookmarks to switch between Active and Exit customer views.
Custom Tooltip on the Credit Card Status chart that displays customer distribution and churn rate by Credit Score without adding extra visuals to the dashboard.

## Tools & Technologies
• Power BI
• Power Query
• DAX
• Data Modeling
• Data Visualization

## Key Insights
• Inactive customers have a higher likelihood of churning than active customers.
• Churn varies across different age groups and tenure levels.
• Customer geography shows noticeable differences in churn distribution.
• Credit Score categories and credit card ownership provide additional context for understanding customer behavior.
• Yearly analysis helps identify changes in churn trends over time.
